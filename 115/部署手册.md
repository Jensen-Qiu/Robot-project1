# 115 机器人节拍优化版 —— 部署手册（移植到同型号同工位机器人）

> 目标：把本 `115/` 代码部署到**另一台同型号 G2 机器人**，使其在相同 QJX 产线任务上跑起优化后的循环。
> 本手册区分【可直接复制】与【必须现场重做】。**代码能复制，但 dz 标定、视觉示教、地图导航点是机器/现场相关的，无法跳过。**

## 0. 适用前提（不满足则需额外处理）
- 目标机与源机 **同型号 G2（g02）**、**相同工作任务**、**相同物理场地同一工位**、**激光重定位**（非纯里程计）。
- 目标机已装机器人软件栈（本套实测 **RB 2.3.5 / Python 3.10**）。
- 工作目录硬编码为 `/data/wxf0721/runtime/programs/` 与 `/data/wxf0721/runtime/`（部署脚本会建）。

## 1. 下载代码
```bash
# 目标机或开发机（conda 自带 git 可能报 curl 错，用系统 git /usr/bin/git）
git clone https://github.com/Jensen-Qiu/Robot-project1.git ~/Robot-project1
cd ~/Robot-project1/115
```

## 2. 装 pip 依赖
```bash
source /home/agi/app/env.sh /home/agi/app
python3 -m pip install -r requirements.txt   # paho-mqtt numpy opencv-python scipy
```

## 3. 准备外部 SDK（不在仓库）
- `agibot_gdk`：随机器人软件自带（`/home/agi/app/gdk/lib`），无需安装。
- 视觉包 `G2_AprilTag_Placement_0.2.0`：从源机对拷到目标机 `/home/agi/`：
  ```bash
  sshpass -p '1' scp -r agi@<源机IP>:/home/agi/G2_AprilTag_Placement_0.2.0 /home/agi/
  ```

## 4. 一键铺代码 + 冒烟测试
```bash
cd ~/Robot-project1/115
bash deploy_115.sh
```
脚本会：建目录 → 铺 `programs/*` 到 `/data/wxf0721/runtime/programs/`、`minth.py` 到 `/data/wxf0721/runtime/` → 赋权 → 冒烟测试（agibot_gdk / 视觉包 / pip / minth import）。全 OK 再继续。

## 5. 迁移地图 + 导航点 + 动作库（机器相关，必做）
同型号同工位 + 激光重定位时可从源机迁移；否则现场重建图。地图是三层结构，须配套迁移：
1. **底层地图** `/home/agi/app/data/`（map.pcd / grid_map / gravity.txt / keyframes）
2. **导航点+WBC动作** `/data/wxf0721/datas/robot_data.db`（map_points 表 + joints 表）
3. **平板登记** `/data/dlb/dlb.db` 的 maps 表（需改 aid、设 is_current，dlb 重启）

> 详细命令见仓库根 README / `trans-lessonlearn` 移植经验文档第二部分（三层地图迁移、migrate_map.py、重定位验证）。
> **本套 `joints` 表必须含 WF1/WF2/XL1/XL2/SL1-3/WQ1-3/FW 等关节动作**（垂直下放标定依赖 WF1/WF2、XL1/XL2）。

## 6. 标定放料下放落差 dz（机器相关，必做）
`wf_vertical_place_dz.json` 里的 dz 是**源机 115 的值**，目标机必须重标：
```bash
# 确保：无料、无遮挡、右臂周围安全、未插充电、视觉服务未运行
source /home/agi/app/env.sh /home/agi/app
cd /data/wxf0721/runtime/programs
python3 wf_vertical_place_115.py calibrate --station WF   # 会驱动右臂到 WF1/WF2 读末端Z
python3 wf_vertical_place_115.py calibrate --station XL   # 会驱动右臂到 XL1/XL2
python3 wf_vertical_place_115.py show                     # 确认两工位 dz 已写入(正数、几厘米)
```
标定后按放料效果微调（改 json 的 dz_m 即可，不用重标/重启服务）。

## 7. 示教视觉参考（机器相关，必做）
`*_reference.json`（pick_sl1 / pick_wq / pick_xl / place）是源机现场示教的几何参考，
相机外参/工装位置不同，目标机**位置对不上会超限回退固定点位**。程序启动时 `_auto_rebind_references()`
会自动更新 boot_id（免手改），但几何参考需按目标机现场重新示教 4 个工位。

## 8. 现场调参（按目标机实际）
`all_machin_plc_vision_loop_onestep.py` 内各工位参数（rot_comp / xy_tol_mm / one_step_verify）、
`SETTLE_AFTER_GO_S`（停稳时间）、WF 后退距离等，是 115 现场调出来的，目标机按放料质量/节拍重调。
当前 115 生效值见本目录 `README.md` 参数表。

## 9. 试跑验证
```bash
# 1) 起视觉常驻服务(后台守护，未插充电)
bash /data/wxf0721/runtime/programs/run_vision_align_server_115_daemon.sh start
# 2) 带节拍记录器 + 常驻 跑主控
bash /data/wxf0721/runtime/programs/run_loop_onestep_profile_115.sh server
```
- 先单测导航点到位、各工位纠偏/放料正常，再连续跑 10+ 轮看节拍(logs/cycle_summary_115.csv)与放料质量。
- 任何异常：停视觉服务(客户端自动降级)或 `unset VISION_USE_SERVER` 回原路径。
